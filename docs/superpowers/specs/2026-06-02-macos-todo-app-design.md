# macOS 待办项管理应用设计文档

## 概述

一个 macOS 原生待办项管理应用，支持按分类管理待办项，可通过全局快捷键快速添加和管理任务。

## 视觉风格

**风格**：柔和渐变（Soft & Warm）

| 属性 | 浅色模式 | 深色模式 |
|------|----------|----------|
| 背景 | `#F8F6FF` | `#16162A` |
| 侧边栏 | `.ultraThinMaterial` | `.regularMaterial` |
| 主文字 | `#2D2D3A` | `#E8E8FF` |
| 次要文字 | `#8B8BA7` | `#6B6B8A` |
| 强调色 | 紫色渐变 `#7C3AED → #A855F7` | 同左 |
| 悬停背景 | `#EDE9FE` | — |

- **字体**：SF Pro Rounded
- **圆角**：10pt（列表项）、16pt（快捷输入窗口）
- **阴影**：`0 2px 12px rgba(0,0,0,0.08)`
- **间距**：10 / 18 / 28pt 网格

## 技术选型

- **框架**：Swift + SwiftUI
- **数据存储**：Core Data
- **系统要求**：macOS 13.0+

## 核心功能

### 分类管理

- 用户可创建、编辑、删除分类
- 分类支持拖拽排序
- 删除分类时级联删除其下所有待办项

### 待办项管理

每个待办项包含：
- 标题（必填）
- 完成状态
- 截止日期（可选）
- 优先级（低/中/高）

已完成的待办项移至列表底部"已完成"折叠区域。

### 全局快捷键

默认 `⌘ + Shift + T` 唤起快捷输入窗口，可在设置中自定义。

## 数据模型

### Category

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Int64 | 自增主键 |
| name | String | 分类名称 |
| displayOrder | Int16 | 排序顺序 |
| createdAt | Date | 创建时间 |
| items | [TodoItem] | 关联的待办项（一对多） |

### TodoItem

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Int64 | 自增主键 |
| title | String | 待办项标题 |
| isCompleted | Bool | 是否完成 |
| dueDate | Date? | 截止日期（可选） |
| priority | Int16 | 优先级（0=低, 1=中, 2=高） |
| createdAt | Date | 创建时间 |
| category | Category | 所属分类（多对一） |

### 存储位置

`~/Library/Application Support/TodoApp/`（由 Core Data 自动管理）

### 删除规则

删除分类时级联删除其下所有待办项（Cascade）。

## 界面设计

### 主窗口

侧边栏 + 列表布局：

```
┌─────────────────────────────────────────────────┐
│  工具栏：[+ 新待办项]              [🔍 搜索]    │
├────────────┬────────────────────────────────────┤
│            │  分类名称标题                        │
│  工作      ├────────────────────────────────────┤
│  家庭      │  ☐ 待办项 1      高优先级  明天     │
│  学业      │  ☐ 待办项 2      中优先级  --       │
│            │  ☐ 待办项 3      低优先级  周五     │
│ ──────── │────────────────────────────────────┤
│  + 新分类  │  ▼ 已完成 (2)                       │
│            │    ☑ 已完成项 1                     │
│            │    ☑ 已完成项 2                     │
└────────────┴────────────────────────────────────┘
```

**交互**：
- 点击左侧分类切换右侧内容
- 双击分类名可重命名
- 右键分类显示菜单（重命名、删除）
- 拖拽分类可调整顺序
- 右侧待办项支持单击勾选、双击编辑、右键菜单
- 底部"已完成"区域默认折叠，点击展开

### 快捷输入窗口

悬浮 Panel，全局快捷键唤起，出现在屏幕中央偏上：

```
┌─────────────────────────────────────────┐
│  [工作 ▼]                    ✕ 关闭    │
├─────────────────────────────────────────┤
│  输入待办项标题...                       │
├─────────────────────────────────────────┤
│  优先级: ○低 ●中 ○高    截止: [选择日期]  │
├─────────────────────────────────────────┤
│  ☐ 待办项 1                             │
│  ☐ 待办项 2                             │
│  ☑ 已完成项 (点击可取消完成)             │
├─────────────────────────────────────────┤
│           [添加] 或 按 Enter            │
└─────────────────────────────────────────┘
```

**交互**：
- 顶部下拉框显示当前分类，可切换
- 切换分类后，下方列表显示该分类的待办项
- 输入标题后按 Enter 或点击"添加"创建待办项
- 点击列表中的待办项可勾选完成/取消完成
- 按 Esc 或点击窗口外部关闭
- 窗口失去焦点自动隐藏

## 技术要点

1. **全局快捷键**：使用 `HotKey` 库（Swift Package）或 Carbon API 注册系统级快捷键
2. **悬浮窗口**：使用 `NSPanel` 配合 `.floating` 和 `.nonactivatingPanel` 样式
3. **主窗口布局**：SwiftUI 的 `NavigationSplitView`（macOS 13+）
4. **Core Data + SwiftUI**：使用 `@FetchRequest` 和 `@Environment(\.managedObjectContext)`
